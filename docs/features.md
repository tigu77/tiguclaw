전부 있습니다. 하나도 버리지 않았습니다.

## 무엇을 하나

- **Claude Code 의 도구를 그대로** — 파일 읽기·쓰기·편집, 쉘 실행, 웹 검색, 스킬, 서브에이전트, 훅, 슬래시 명령, 영구 메모리.
- **여러 LLM, 하나의 비서** — `anthropic`·`openai`·`codex`(ChatGPT)·`ollama`(로컬)·`google`(Gemini)이 기본으로 들어 있고, **OpenAI 호환 엔드포인트라면 무엇이든**(OpenRouter·Groq·vLLM·직접 띄운 것) 설정 세 줄로 붙습니다. `provider:model` 한 줄로 섞어 쓰세요. 바꿔도 능력은 그대로입니다 — 셸·검색·파일·위임까지 **어느 모델에서나 같은 도구**로 돌기 때문에, 모델을 갈아도 같은 질문에 다른 답이 나오지 않습니다.
- **항상 켜짐** — 백그라운드 서비스로 상시 실행되고, 죽으면 스스로 재시작합니다.
- **부탁하면 스스로 업데이트** — "업데이트해줘" 한마디(또는 `/update`)면 최신 코드를 받아 재시작하고, 다 되면 알려줍니다. 손으로 `git pull` 할 필요 없어요. 기억·세션은 그대로 이어지고, 새 코드가 실행 가능하게 빌드되지 않으면 이전 버전으로 롤백해 계속 돌아갑니다. 받을 게 있으면 **대시보드 우측 상단에 알려주니** 굳이 확인하러 다니지 않아도 됩니다 — 눌러서 바로 받으면 화면도 알아서 새로고침됩니다.
- **텍스트 말고 버튼으로 묻습니다** — 고르라고 할 때 누를 수 있는 보기를 띄웁니다(텔레그램·대시보드는 버튼, CLI는 번호). 어느 채널이든 똑같습니다.
- **타이핑 대신 말로** — 텔레그램에 음성 메시지를 보내거나 대시보드 마이크를 꾹 누르고 말하면, 받아 적고 바로 일을 시작합니다. 전사도 다른 능력처럼 설정으로 고르세요 — 로컬 모델이든 클라우드든.
- **일하는 중에 끼어들 수 있습니다** — 비서가 작업 중일 때 메시지를 보내면, 턴이 끝나길 기다리거나 처음부터 다시 시키지 않고 진행 중인 작업에 그대로 반영합니다.
- **다채널 단일 인격** — 텔레그램·CLI·HTTP·웹 대시보드 어디로 들어와도 같은 비서고, 대화 맥락도 공유합니다. 폰에서 시작한 대화를 책상에서 그대로 이어갑니다.
- **무거운 일도 사소한 일도 위임** — 큰 목표는 **매니저**에게 통째로 넘겨 대화를 끊지 않고(매니저는 그 안에서 필요한 만큼 사람을 붙입니다), 가벼운 일은 더 싼 모델 등급으로 내려보냅니다. 어느 일을 어느 등급에 맡길지는 모델 프로파일로 정하세요.
- **여러 명을 동시에, 그리고 잊지 않고** — 서브에이전트를 여럿 띄워두고 대화를 이어갈 수 있습니다. 맡긴 쪽은 **결과를 받기 전엔 끝나지 않으므로**, 맡겨놓고 잊히는 일이 없습니다. 도는 중에 지시를 얹거나 멈출 수도 있습니다.
- **일하면서 배웁니다** — 자기 실수가 반복되면 그걸 운영 교훈으로 정리해 다음엔 따르고, 재사용할 만한 워크플로우다 싶으면 — 처음 보는 것이라도 — 알맞은 자리(프로젝트 전용/공통)의 스킬로 만들자고 제안합니다. 전부 *제안 → 승인*이고, 몰래 자기를 고치지 않습니다.
- **자기 이상을 스스로 알아챕니다** — 최근 기록을 훑어 조용히 잘못된 것(도착 안 한 예약 알림, 죽은 작업 같은)을 찾아 먼저 보고합니다. 되돌릴 수 있는 안전한 조치 — 그 알림 한 번 다시 보내기 같은 — 는 알아서 하고 알려주며, 나머지는 사용자에게 가져옵니다.
- **멈추면 멈췄다고 말합니다** — 도구가 응답 없이 붙잡혀 있으면 화면에 알리고, 텔레그램으로 대화 중이었으면 그쪽으로도 알립니다. 끝내 응답이 없으면 턴을 끊습니다. "돌고 있는 건지 멈춘 건지 모르겠는" 시간을 없앴습니다.
- **대화 이름도 말로 바꿉니다** — "이 대화 이름 '핫딜 리팩터링'으로 바꿔줘" 처럼 부탁하면 됩니다. 여러 대화를 굴릴 때 어느 게 뭔지 헷갈리지 않아요.
- **데이터는 내 컴퓨터에** — 세션·메모리·DB 전부 로컬(`~/.tiguclaw`)에.
- **대시보드에서 시켜도 텔레그램으로 같이 받습니다** — 입력창의 📤 로 "이 답도 함께 보낼 채널"을 켜두면, 자리를 비운 사이 끝난 긴 작업도 폰으로 옵니다. 그 메시지에 **답장하면 그 답을 만든 대화로** 들어가요 — 여러 대화가 한 방에 섞여 와도 헷갈리지 않습니다.
- **다음에 할 말을 제안합니다** *(기본 꺼짐)* — 턴이 끝나면 입력창에 회색 글씨로 떠 있고, Tab(모바일은 입력창 터치)이면 채워집니다. 보내는 건 직접 하셔야 해요. 매 턴 토큰을 조금 쓰기 때문에 **설정 화면에서 켜야** 켜집니다.
- **밖으로 나간 호출도 기록됩니다** — 내가 연 HTTP 엔드포인트와 LLM 게이트웨이 호출이 한 화면에 남습니다. 주고받은 **내용은 저장하지 않고** 어떤 모델이 몇 건을, 토큰·소요·성공 여부가 어땠는지만요.
- **화면 언어를 고릅니다** — 설정에서 언어를 바꾸면 대시보드가 그 언어로 뜹니다(영어가 함께 들어 있습니다). 새 언어는 홈의 `locales/` 에 `<언어>.json` 파일 하나를 넣으면 늘어나고, 코드는 건드리지 않습니다. **반만 번역해도 화면이 안 깨져요** — 빠진 문구는 기본 언어로 나오니 몇 줄씩 옮겨 가며 써도 됩니다.
- **새로고침해도 자리를 잃지 않습니다** — 보던 화면, 세션 탭, 백그라운드 패널 상태가 그대로 돌아옵니다.

## 다른 점

비슷한 도구와 갈리는 지점들입니다.

- **웹 대시보드.** 일하는 과정이 한 스텝씩 실시간으로 뜹니다 — 추론과 도구 실행이 일어난 순서대로, 편집은 diff 와 파일 줄 번호까지. 세션 탭으로 여러 대화를 나란히 두고, 옆 패널에서 백그라운드 작업을 따라갑니다. 재시작해도 스크롤백이 남고, 입력창은 셸처럼 ↑/↓ 로 이전 입력을 꺼내거나 `#태그`로 맥락을 겁니다.

  <br><sub>웹 대시보드 — 일하는 과정이 한 스텝씩, 오른쪽 패널에서 매니저·서브에이전트가 도는 걸 그대로 봅니다.</sub>

- **폰에서도 씁니다.** 데스크톱 화면을 줄인 게 아니라 모바일 레이아웃이 따로 있습니다 — 서랍 내비게이션, 마스터-디테일 패널, 폰 키보드에 맞춘 입력창. 소파에서 오래 걸리는 작업을 확인하거나 일을 시켜두고, 책상에서 같은 대화로 이어서 끝냅니다.
- **프로젝트.** 폴더를 주고 "프로젝트로 등록해줘" 해도 되고, 폴더 없이 "이런 프로젝트 해보자" 해도 됩니다 — 앞은 그 폴더를, 뒤는 작업 폴더를 새로 만들어 등록합니다. 설명·상태를 담은 `PROJECT.md` 는 비서가 쓰고요(있으면 그대로 씁니다). 등록하면 `#이름` 만 붙여 그 프로젝트 얘기를 하고, 그 폴더 전용 스킬·서브에이전트·MCP 도구가 같이 켜집니다.
- **외부 MCP 서버를 즉석에서 연결.** MCP 서버를 추가해달라고 하면 그 외부 도구를 배선합니다 — 전역으로든 특정 프로젝트로든, 코어는 안 건드립니다.
- **내가 통제하는 모델 티어.** 모델 프로파일(`default`·`high`·`mid`·`low`)을 크로스-프로바이더 풀 + 자동 폴백으로 이름 붙입니다. 메인 턴은 한 티어, 서브에이전트·매니저는 다른 티어로 돌아요 — 대화로 편집하거나 `/models` 로 목록을 봅니다.
- **일하는 걸 지켜봅니다.** 서브에이전트와 오래 걸리는 매니저가 추적 가능한 잡으로 돌아서, 대시보드에서 상태·단계·결과를 따라갑니다.
- **말로 확장합니다.** 새 슬래시 명령·HTTP 엔드포인트·예약 작업·재사용 스킬 — 코어를 패치하지 않고 홈 아래 *데이터*로 추가합니다(그래서 업데이트가 깨끗하게 유지돼요).
- **내 앱의 LLM 백엔드로 씁니다.** OpenAI 호환 클라이언트를 내장 게이트웨이(`POST /v1/chat/completions`·`GET /v1/models`)로 향하게 하면, 내 앱이 이 풀을 그대로 물려받습니다 — 프로바이더 간 자동 폴백, 이미지 입력, 함수 호출 그대로 통과, 원하면 스트리밍까지. 프로바이더마다 SDK 하나씩 대신 엔드포인트 하나로요. 게이트웨이 토큰을 넣기 전엔 꺼져 있고, 응답은 *내 앱*으로 나갑니다 — 비서 인격이 새지 않아요.
- **얼마 썼는지, 그리고 무엇이 답했는지 보입니다.** 매 턴의 입력·출력 토큰과 캐시 적중률이 채팅에 바로 뜹니다 — 낭비가 짐작이 아니라 숫자로 보여요. 답변·도구 실행·백그라운드 작업마다 *실제로* 응답한 모델이 함께 붙습니다 — 한도에 걸려 폴백으로 넘어가면 내가 지정한 등급과 달라지기 때문입니다. 쉬고 있는 모델은 `/status` 가 이름으로 알려줍니다.
- **모든 모델에서 도는 훅.** `settings.json` 에 Claude Code 식 `hooks` 블록을 넣으면 도구 호출을 관찰하거나 차단합니다(턴 앞뒤도요). 그 *같은* 설정이 `anthropic`·`codex`·`openai` 어디서 턴이 돌든 똑같이 동작합니다. [훅](hooks.md) 참고.


## 뭘 시킬 수 있나

유능한 팀원한테 말하듯 — 텔레그램·CLI·HTTP 어디서든. 예시 몇 개:

**코드 & 내 컴퓨터**
- "`~/projects/api` 의 실패한 테스트 고치고 브랜치 하나 따줘."
- "디스크 뭐가 잡아먹는지 보고 확실한 쓰레기만 정리해줘." *(삭제 전엔 꼭 물어봅니다)*
- "이 파일들 읽고 인증이 어떻게 도는지 설명해줘."

**조사 & 글쓰기**
- "오늘 AI 뉴스 조사해서 짧게 요약해줘."
- "이 메시지에 답장 초안 써줘: …"
- "내 용도에 두 라이브러리 비교하고 하나 추천해줘."

**오래 걸리는 일도 기다림 없이**
- "이 40개 페이지 긁어서 표로 만들어줘." → 무거운 일은 백그라운드 매니저에 넘기고 대화는 계속, 끝나면 알려줍니다.
- 반복·대량·단순 작업은 무료 로컬 모델에 위임 — 모델 프로파일에서 낮은 등급을 `ollama` 로 지정해두면 그쪽으로 내려갑니다.

**기억 & 예약**
- "나 TypeScript 랑 공백 2칸 선호하는 거 기억해." → 모든 대화에 걸쳐 유지.
- "평일 아침 9시마다 X 요약해서 보내줘."
- "지난주 DB 관련해서 우리 뭐로 정했지?"

**그냥 말로, 내 비서로 만들기**
- "질문 3개 물어보는 `/standup` 명령 추가해줘." → 명령을 등록(텔레그램 메뉴도 실시간 갱신).
- "내 다른 앱이 호출할 HTTP 엔드포인트 하나 열어줘." → 코어 안 건드리고 연결.
- "이 작업 흐름을 재사용 스킬로 만들어줘."

**어디서든** — 폰(텔레그램)·터미널(CLI)·내 앱(HTTP). 같은 비서, 같은 기억.

> 내 컴퓨터의 쉘·파일에 접근할 수 있고, **파괴적이거나 되돌릴 수 없는 작업 전에는 반드시 승인을 받습니다**([`docs/security.md`](docs/security.md)).

## 어떻게 만들어졌나

- **코어** — 단일 LLM 런타임(어댑터 풀: claude / codex / openai / ollama / google) + 라우터 + SQLite 스토어(세션·메모리·transcripts).
- **채널** — 텔레그램 / CLI / HTTP 어댑터가 추상 의도를 채널별로 렌더.
- **플러그인** — 스케줄러(cron)·파일 워치·대시보드·http-bridge(대시보드 API + OpenAI 호환 게이트웨이)·self-growth(학습·제안) — 코어를 안 건드리고 확장.
- **능력은 데이터** — `<home>/` 아래 에이전트·스킬·메모리·훅으로 무한 확장(마이크로커널 + 플러그인 생태).
