# computer-use — 컴퓨터 사용 (화면 관측 + 조작)

비서가 **지금 화면을 찍어서 보고, 그 화면을 누른다.**

> ★조작은 **되돌릴 수 없다.** 이 플러그인을 켜는 것은 «비서에게 이 기계의 마우스와
> 키보드를 준다» 는 뜻이다. 무엇을 묻고 무엇을 자동으로 하는지는
> `skills/computer-use/SKILL.md` 가 정한다.

## 켜기 전에 — 기계마다 걸리는 것이 다르다

**macOS** 는 권한이 **둘**이고, 서로 다르다.

    화면 기록      시스템 설정 → 개인정보 보호 및 보안 → 화면 기록      ← 관측
    손쉬운 사용    시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용    ← 조작

둘 다 «데몬을 실행하는 앱» 을 켜고, **그 뒤 데몬을 한 번 재시작**해야 반영된다.
★관측만 되고 조작이 안 되는 상태가 정상적으로 존재한다 — 권한이 다르기 때문이다.

**Windows** 는 화면·입력에 권한 동의가 **없다.** 대신 **세션**이 그 자리를 차지한다 —
데몬이 서비스(Session 0)로 떠 있으면 사용자 화면이 아예 보이지 않고 입력도 닿지 않는다.
로그인한 사용자 세션에서 실행되어야 한다.
★그리고 **관리자 권한으로 뜬 창**(UAC 대화상자 등)에는 입력이 **조용히 안 닿는다.**
미리 알 방법이 없어서 막지 못한다 — 재관측이 유일한 판정이다.

★어느 쪽이든 도구는 **매달리지 않고 곧바로 안내를 돌려준다**(mac 실측 71~93ms).
 이게 중요한 이유: MCP 도구 호출 천장이 11분이라, 매달리면 턴이 그만큼 묶인다.

## 할 수 있는 것

**관측** — 전체 화면(주 디스플레이) · 특정 디스플레이 · **영역**
(★화면 밖 영역은 거절하고, 가장자리에 걸치면 **화면 안쪽만** 찍고 그 사실을 말한다)

**조작** — 클릭(더블·우클릭 포함) · 글자 입력(한글 그대로) · 키 조합 · 드래그 · 스크롤.
전부 **수식키를 누른 채**로 할 수 있다(`shift`+드래그, `ctrl`+클릭, `alt`+스크롤).

## 안전 장치 — 조용히 실패하지 않게

- **사람이 쓰는 중이면 조작하지 않는다.** 방금까지 사용자가 키보드·마우스를 썼으면 막는다.
- **좌표는 «관측 그림의 픽셀»** 이고, 그 그림의 «화면 id» 를 같이 줘야 한다.
  ★**조작을 한 번 하면 그때까지의 화면 id 가 전부 무효**가 된다 — 화면이 바뀌었으니까.
  낡은 그림 좌표로 누르는 길이 구조적으로 막혀 있다.
- **같은 기계를 둘이 동시에 만지지 못한다**(작업 하나가 쥐고 있으면 다른 쪽은 기다린다).
- **실패하면 «했다» 고 말하지 않는다.** 왜 막혔는지와 무엇을 하면 되는지를 돌려준다.
- 계획이 눌러둔 키·버튼은 **취소되어도 떼어진다**.

★그래도 **«보냈다» 가 «됐다» 는 아니다** — 앱이 그 단축키를 안 받거나, 스크롤이 끝에 닿아
있거나, 권한이 높은 창이면 입력은 나갔는데 아무 일도 안 일어난다. **판정은 재관측이다.**

## 못 하는 것

- **특정 창만** 찍기·창 고르기 — 창 열거가 아직 없다(전체 화면·디스플레이·영역까지)
- **Linux(X11/Wayland)** — 구현이 없다. 실행부가 없는 기계에선 도구가 아예 안 뜬다
  (있는 척하고 실패하지 않는다)

## 어느 기계에서 되나

| | 관측 | 조작 |
|---|---|---|
| macOS | 구현·실사용 | 구현·실사용 (손쉬운 사용 권한 필요) |
| Windows | 구현 · 실기 확인(모니터 2개·DPI v2) | 구현 · 실기 확인(모니터 2개, 보조 화면 클릭 포함) |
| Linux(X11/Wayland) | 없음 — 도구가 안 뜬다 | 없음 |

## 프레임은 어떻게 남나

- 자리: `<홈>/plugins/computer-use/` — 플러그인을 지우면 같이 지워집니다
- 형식: JPEG(긴 변 1600px, 품질 80). 같은 화면 기준 PNG 대비 **약 6배 작고**, 작은 글자는
  그대로 읽힙니다
- 데이터베이스에는 **경로만** 들어갑니다(그림 자체는 안 들어갑니다)
