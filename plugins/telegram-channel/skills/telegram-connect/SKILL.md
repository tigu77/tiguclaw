# 텔레그램 연결

연결은 **대시보드 → 플러그인 → 텔레그램 채널(telegram-channel)** 설정에서 한다. `.env` 를 직접 고치게 하거나 터미널 명령을
시키지 않는다 — 그 화면이 같은 파일에 안전하게 쓴다.

## 사용자에게 안내할 순서

1. **봇 만들기** — 텔레그램에서 **@BotFather** 를 열고 `/newbot` 을 보낸다. 이름과 아이디(`…bot` 으로 끝남)를 정하면
   `123456789:AA…` 모양의 토큰을 준다.
2. **토큰 넣기** — 대시보드 플러그인 화면의 텔레그램 «봇 토큰» 칸에 붙여넣는다(값은 다시 화면에 나오지 않는다).
3. **재시작** — 화면 위 «지금 재시작» 을 누른다(또는 사용자가 원하면 비서가 재시작한다). 이제 봇이 메시지를 받는다(아직 잠긴 상태).
4. **봇에게 말 걸기** — 텔레그램에서 방금 만든 봇을 찾아 아무 말이나 한 번 보낸다(아직 답은 없다 — 정상이다).
5. **내 ID 찾기** — 같은 화면의 «소유자 ID» 옆 «내 ID 찾기» 를 누르고, 목록에서 **자기 이름**을 고른다. 고르는 즉시 통한다
   (재시작 다시 필요 없음) — 봇에게 다시 말을 걸면 답한다.

## 지킬 것

- ★**토큰을 채팅으로 받지 않는다.** 붙여넣겠다고 하면 위 2번 칸으로 안내한다 — 채팅에 쓴 값은 대화 기록과 모델 요청에 남는다.
  이미 채팅에 붙여넣었다면 그 사실을 알리고 BotFather 의 `/revoke` 로 새 토큰을 받으라고 권한다.
- 소유자 ID 는 사용자가 **고른다** — 목록 맨 위를 알아서 넣지 않는다(봇 이름이 알려지면 남이 먼저 말을 걸 수 있다).
- 소유자 ID 가 비어 있으면 봇은 **잠긴다**(아무에게도 답하지 않는다). 연결이 안 된다면 먼저 이 칸을 확인한다.
- 한 토큰은 **한 곳에서만** 받을 수 있다 — 같은 토큰을 다른 기기·인스턴스에도 넣으면 서로 끊는다(로그에 `409`).
- 연결 뒤 확인은 데몬 로그의 `telegram:` 줄로 한다(`allowlist 활성` · `차단된 접근` · 폴링 오류).
